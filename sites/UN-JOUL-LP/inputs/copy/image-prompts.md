# image-prompts.md
ChatGPT（画像生成）に貼り付けて使うプロンプト集
共通トーン：焦げ茶(rgb(37,30,28)) × ベージュゴールド(rgb(182,150,108)) × 白。落ち着いた高級感、直線的で装飾少なめ。

---

## 1. ロゴ（logo.png）
```
シンプルでミニマルな、フランス語の造語「Un Jour」をロゴタイプ化したワードマークを作って。
セリフ体、細めのウェイト、レターイングは少し広め。
色は焦げ茶(#251E1C)、背景は透明。
装飾的なアイコンは不要、文字のみのロゴ。
高級ヘアサロンのブランドロゴとして使えるクオリティで。
```

## 2. メインビジュアル / FV背景（hero-main.jpg）
```
落ち着いた雰囲気の室内ヘアサロンの写真風イメージ。
ナチュラルな光が窓から差し込む個室スタイルの美容室、
チェアとミラー、観葉植物、ベージュとダークブラウンを基調にしたインテリア。
人物は写さず、空間そのものの高級感・静けさを強調した構図。
写真のようにリアルなテイストで、横長（16:9）。
```

## 3. サービス紹介1：カウンセリング風景（service-counseling.jpg）
```
落ち着いた色調の美容室の個室で、
スタイリストと思われる後ろ姿とお客様が向かい合って話している様子のイメージ写真。
顔がはっきり写らない構図（後ろ姿・シルエット中心）。
色調はベージュ、ダークブラウン、白を基調に、
柔らかい自然光が差し込む落ち着いた雰囲気。
```

## 4. サービス紹介2：ヘッドスパ（service-headspa.jpg）
```
リラックスした雰囲気のヘッドスパ施術風景のイメージ写真。
洗面台に仰向けで髪を洗われているシーンだが、顔は伏せ気味・目を閉じた状態で写す。
タオルはベージュ系、照明は暖色でやわらかい。
高級スパのような静けさと清潔感を感じさせる構図。
```

## 5. トリートメント/髪質改善イメージ（service-treatment.jpg）
```
艶やかで健康的な髪の毛のクローズアップ写真風イメージ。
髪の質感・ツヤが伝わるマクロ撮影風の構図。
背景はぼかした暖色系（ベージュ〜ブラウン）。
広告的すぎず、上質な素材感を意識したナチュラルなトーン。
```

## 6. 店舗外観・実績訴求用（interior-wide.jpg）
```
高級感のある美容室の店内を広く写したイメージ写真。
複数のセット面、間接照明、観葉植物、木目とベージュを基調にした内装。
人物なし、空間デザインに焦点を当てた横長の構図。
```

## 7. アイコン（icons/icon-private.png, icon-counseling.png, icon-care.png）
```
ミニマルでモダンな、カラー付きのフラットデザインアイコンを3種類作って。
1つ目：individual/プライベート空間を示す「個室」アイコン
2つ目：対話・カウンセリングを示す「会話吹き出し」アイコン
3つ目：髪・ケアを示す「髪の毛としずく」アイコン
配色は、焦げ茶(#251E1C)とベージュゴールド(#B6966C)を中心に、差し色として使う程度。
背景は白または透明、装飾は増やしすぎず、上質で落ち着いた印象のフラットアイコンで。
3つとも同じスタイル・同じ配色トーンで統一して。
```
