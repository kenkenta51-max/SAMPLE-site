# Amiの維持事項

- 作業開始時に `README.md` と `CODEX_HANDOFF.md` を読む。
- このパッケージは承認済みの完成版。依頼なしにデザインや内容を作り直さない。
- 紙・木・植物、オリーブとブラウン、髪の流れの線画とカラーの筆跡、写真を重ねる構図を維持する。
- ヘアカラー診断の明示的な日本語見出しと3枚の写真、写真付きメニューカード、選択写真と料金の連動を維持する。
- 料金、所要時間、メニュー、スタッフ、文章は依頼なしに変更しない。
- 実際の予約・決済・メール送信を接続しない。デモ表示を維持する。
- `dist/` はビルド不要の静的サイト。React等へ移行しない。ランタイム依存を増やさない。
- 読み込むCSSの順序は `style.css` → `usability.css` → `atelier.css`。
- 表示不具合は必要な箇所に限定して修正。スマホでの読みやすさ、44px程度の操作範囲、キーボード、動きを減らす設定を維持する。
- UIの修正には `.agents/skills/ui-ux-pro-max/SKILL.md` を読み、必要な検索を行う。スキル自体を独自改変しない。
- 認証情報はコミットしない。既存リポジトリやリモートの内容を強制上書きしない。
- 公開成功はデプロイ結果とURLで確認し、未確認の表示・動作を確認済みと報告しない。
