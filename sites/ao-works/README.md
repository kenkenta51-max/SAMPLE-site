# AO WORKS — PulseGuard AI Portfolio

製造業向けAI予知保全ソリューション「PulseGuard AI」を想定した、営業資料ポートフォリオの静的Webサイトです。

## 構成

- `index.html` — ポートフォリオ本体
- `style.css` — レスポンシブデザイン
- `script.js` — スライド拡大表示
- `slide-01.webp`〜`slide-10.webp` — Web表示用スライド

## Vercelへ公開

1. Vercelで **Add New → Project**
2. GitHubのこのリポジトリをImport
3. Framework Presetは **Other**
4. Build Command / Output Directory は空欄
5. Deploy

## 注意

本ケーススタディはポートフォリオ用の架空案件です。会社名、サービス名、数値、事例、連絡先等は説明用のフィクションです。
