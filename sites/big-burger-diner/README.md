# Big burger Diner

Canvaのメニュー表「茶色 モダン ハンバーガー レストラン メニュー（A4）」をもとにした、ハンバーガー店のLP兼モバイルオーダーのデモです。

- FV: スクロールに合わせて120枚の連番WebP（`assets/frames/`）をcanvasで再生（スマホでは60枚）。Lenisでスムーススクロール。
- セクション: お店の紹介 / 味のこだわり / モバイルオーダー（バーガー・サイド・ドリンク）/ アクセス
- カスタマイズ: サイズ・セット（サイド/ドリンク選択）・トッピング・数量。価格と画像が選択に合わせて変化。
- カート → 注文確認 → 送信演出 → 完了チケット（デモ。実際の注文・決済は行いません）

商品の切り抜き写真・サイド/ドリンク・店舗写真はCanvaの素材と、Canva AIで生成した画像を使用しています。住所・電話番号・地図・創業年などは仮の情報です。
