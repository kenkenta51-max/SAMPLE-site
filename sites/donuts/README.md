# ドーナツ｜Cafe CODIA モバイルオーダー（デモ）

Cafe CODIA のメニュー表をもとに作った、スマホ向けのモバイルオーダーサイトです。
注文・決済はすべてデモで、実際には何も送信されません。

## 主な機能
- 味ごとに背景色が切り替わるFV（自動切り替え・タップ・スワイプ対応）
- スワイプで切り替わる商品ギャラリー
- サイズ・トッピング・ドリンクセットのカスタマイズ（見た目と価格が連動）
- カート追加アニメーション
- 注文確認から注文完了まで

## 使い方
`index.html` をブラウザで開くだけで動きます（ビルド不要・単一ファイル）。

## 注意
商品写真はCanvaで作成したメニュー表から切り出したものです。
