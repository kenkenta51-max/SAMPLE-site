# FLOAT WASH

宇宙をテーマにした架空の24時間コインランドリーのWebサイトです。

**公開URL:** https://kenkenta51-max.github.io/SAMPLE-site/sites/float-wash/

HTML・CSS・JavaScript・生成写真を `index.html` にまとめています。外部ライブラリや画像配信サービスへの依存はありません。

## 操作

- スクロールに合わせて、ドラムへの接近、水滴と星のトンネル、最後のメッセージへ進みます。逆方向へのスクロールで巻き戻せます。
- ドラム中央のボタンで約5秒の自動スクロール演出を再生します。ホイール・タッチ・キー操作で中断できます。
- スマホは上下のスワイプで操作できます。短い横向き画面では通常表示に切り替わります。
- 演出のスキップ、アニメーション停止、端末の動きを減らす設定に対応しています。
- コースの洗濯シーン、FAQ、料金の試算も操作できます。

このサイトは架空ブランドのデモです。写真は生成イメージです。実際の予約・決済・情報送信は行いません。

## 更新と公開

完成版の `index.html` を編集し、リポジトリのルートで `python scripts/build.py` と `python scripts/audit.py` を実行してください。`main` にpushすると、既存のGitHub Pagesワークフローで一覧ページとともに公開されます。
