# MELUA CLINIC / メルアクリニック

架空の医療脱毛クリニックのスマートフォン向けランディングページです。

## 公開サイト

https://kenkenta51-max.github.io/SAMPLE-site/sites/melua-clinic/

## 実装内容

- 夏の海・スプラッシュを使ったファーストビュー
- 料金プラン選択と総額の切り替え
- 自己処理の悩み、選ばれる理由、架空の体験例
- 同一の腕を使用した自己処理の有無の比較スライダー
- 来院の流れ、開閉できるFAQ、予約CTA

## 開発・確認

HTML / CSS / JavaScriptのみで構成され、ビルドは不要です。

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開いて確認できます。PCでは中央にスマートフォン幅で表示します。

## デモについて

クリニック、料金、条件、レビューは架空のサンプルです。画像はAI生成・加工イメージを含みます。肌比較は実際の施術前後の写真ではありません。予約ボタンは説明ダイアログを表示し、実際の予約や個人情報送信は行いません。
