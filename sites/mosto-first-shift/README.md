# MOSTO はじめての接客

添付された「MOSTO 新人接客研修マニュアル」Ver.1.0をもとにした、全10ステージの接客シミュレーションゲームです。

[▶ ブラウザでゲームを遊ぶ](https://kenkenta51-max.github.io/mosto-first-shift/)

## 遊び方

1. `index.html` をブラウザで開きます。インストールは不要です。
2. 「研修スタート」を押し、3つの対応から1つを選びます。
3. スタッフの行動とお客様の反応を見ます。演出は一時停止・スキップでき、マニュアルを開いている間も停止します。
4. 正解・改善点・原典のルールIDとページを確認して次へ進みます。「この対応をもう一度見る」で演出を再生しても点数は増減しません。
5. 10ステージ後にランク、接客タイプ、正答率と復習項目を確認できます。

PCでは1・2・3キーでも回答できます。サウンドは初期状態でOFFです。マニュアルはいつでも開けます。選択肢はプレイごとに並び替わります。時間制限はありません。

ゲームの内容と画像を同梱しています。マニュアルPDF原本は公開していません。ゲーム内では学習に使うルールの要約・ルールID・出典ページを確認できます。通信なしでもローカルで遊べます。記録の送信や個人情報の収集はしません。ブラウザの再読み込みで研修は最初に戻ります。

## 内容

- 来店から退店までの10ステージ
- スタッフ6ポーズ、母親・子どもそれぞれ4表情を別々に制御する店内アニメーション
- 全30選択肢に対応する149場面の演出。正解時は接客の手順、不正解時はお客様の反応と先輩の助言
- 歩いて席へ案内、トレーで配膳、手洗い、責任者への確認・報告、レジ会計、退店・忘れ物確認
- 動きOFFでは演出の待ち時間を省略。「今回の行動と会話を振り返る」で全手順を読める
- 顧客満足度、マニュアル遵守度、接客スキル、スコア
- 安全・衛生・アレルギー・クレームは大きい配点
- 原典のルールID・ページ付き解説とマニュアル
- 最終ランク、接客タイプ、良かった点、改善点、回答の振り返り
- スマートフォン対応、キーボード操作、動きを抑える設定への対応

数値・ランク・会話・店内はゲーム上の設定です。正誤判定はPDF本文のルールに従います。ルールのない見出しは「IDなし」と表示し、独自のルールIDを付けていません。詳しい対応表は `RULES.md` に記載しています。

## ファイル

`index.html` がゲームの入口です。`data.js` が教材内容、`app.js` がゲーム進行、`stories.js` が各選択肢の演出、`motion.js` が人物・小物と再生制御です。画面デザインは `styles.css` と `motion.css`。画像は `assets/` にあります。新しい画像と座標情報は `assets/motion/` にあり、画像を加工せずブラウザ内でコマを表示します。

演出中の会釈・移動・表情や架空の会話は体験を補助するもので、採点に独自のマニュアルルールを追加していません。アレルギー場面では商品の安全性を決めず責任者へ引き継ぎ、遅延場面では未確認の具体的な待ち時間を生成しません。

店内とお客様の画像はこのゲーム用に生成したオリジナル素材です。MOSTOとマニュアルは原典に記載のとおり架空店舗・研修用の設定です。

## 公開方法

GitHub Pagesで `main` ブランチのルートを公開します。ビルドや外部サービスのAPIキーは不要です。

1. `index.html`、JavaScript、CSS、画像を、このリポジトリの `main` ブランチに登録します。PDF原本は含めません。
2. リポジトリの **Settings → Pages** を開きます。画面幅が狭い場合、Settingsは上部の「…」メニュー内にあります。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. **Branch** を **main**、フォルダーを **/(root)** にして **Save** を押します。
5. **Actions** の `pages build and deployment` が完了したら、Pages画面の **Visit site** から公開サイトを開きます。

以後、`main` ブランチのゲームを更新すると、同じURLに自動で反映されます。

[GitHub公式の公開手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
