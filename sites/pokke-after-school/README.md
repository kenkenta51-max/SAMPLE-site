# ポッケ放課後クラブ

架空の児童クラブサイト。`index.html` を開くだけで動作します。HTML・CSS・JavaScript・生成画像を内包し、CDNや外部フォントに依存しません。約5.5MB。

## ページ

TOP、クラブ紹介、あそびと一日、施設と安心、入会案内（料金試算・FAQ）、お知らせ一覧・4記事、見学フォーム、プライバシー。ハッシュルートを使うため、サーバーのルーティング設定は不要です。

## デモ仕様

団体・住所・料金・活動記録は架空です。写真はすべてAI生成。見学フォームは入力→確認→完了を画面内で体験するデモで、データの送信・予約・入力値の永続保存は行いません。完了または画面を離れると入力を消去します。端末内に保存するのは動きの軽減設定だけです。

## 検証

JavaScript構文、DOM操作を伴う56項目の機能検査、単体ファイル内の画像デコードを確認済み。コレクションのビルド・ローカル参照監査も実施。ブラウザ接続エラーにより、ピクセル表示と実機タッチ操作の検証は未完了です。

## 画面全体の扉演出

初期表示では黄色い両開き扉が画面全体を覆います。スクロールジェスチャー・タップ・キーボードで開き、背後にサイトの先頭が現れます。導入中はページ位置を動かさず、開き切った後は通常のスクロールへ切り替えます。余白やスクロール用スペーサーは追加しません。スキップボタンとEscapeで即座に進めます。導入中の背面はinertにし、Tabの移動先を導入内に限定します。動きの軽減設定・JavaScript無効時・下層ページへの直接アクセスでは導入を省略します。ページ内移動で導入を繰り返しません。単体HTMLと確認サイトの両方を更新しています。
