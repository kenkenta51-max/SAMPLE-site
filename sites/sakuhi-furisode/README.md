# 振袖 咲日 — SAKUHI

架空の振袖レンタル・撮影アトリエ。店名・衣裳名・スタッフ・店舗情報は創作、人物とアトリエの写真は画像生成によるものです。参考サイトの写真・文章は使用していません。

`index.html` だけで動作します。CSS、JavaScript、SVG、生成画像をすべて内包し、外部フォントやライブラリへの通信はありません。ファイルを直接開くこともできます。

トップ、コレクション、衣裳詳細6件、プラン一覧・詳細3件、撮影紹介、ブランド紹介、店舗案内、FAQ、プライバシー、相談予約の各画面をハッシュルーティングで切り替えます。

色別フィルター、お気に入り（端末内保存）、プラン試算、FAQ絞り込み、予約内容確認・デモ完了まで操作できます。予約・問い合わせ・決済・個人情報の外部送信は行いません。

リポジトリの標準手順で `python3 scripts/build.py`、`python3 scripts/audit.py` を実行するとコレクションに追加されます。公開・pushはこの制作作業では行いません。

検証結果は `QA.md`、画面見本は `previews/` に保存しています。HTMLは約10.3 MBです（PNG生成画像を内包）。
