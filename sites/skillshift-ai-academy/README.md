# SkillShift AI Academy LP

生成AI初心者の会社員に向けた、架空のオンラインAIスクール「SkillShift AI Academy」のランディングページ制作プロジェクトです。

## このLPの目的

- 20〜40代の会社員に、AIを仕事で活用する具体的なイメージを持ってもらう
- 「自分でも使えそう」「明日の仕事で試せそう」と感じてもらう
- 無料説明会への申込みにつなげる

メインCTAは、すべて`無料説明会に参加する`で統一します。

## フォルダ構成

```text
skillshift-ai-academy/
├─ AGENTS.md                 Codexが必ず守る案件固有ルール
├─ README.md                 このプロジェクトの説明と作業手順
├─ inputs/                   要件・原稿・ワイヤー・完成イメージ
│  └─ references/            FV、全体デザイン、競合の参考画像
├─ rules/                    過去に作成したデザインルール一式
├─ assets/
│  └─ images/                Webサイトで実際に使う画像素材
├─ src/                      HTML、CSS、JavaScriptなどの制作コード
├─ public/                   公開用ファイル（構成に応じて使用）
├─ qa/                       表示確認・チェック結果
└─ delivery/                 納品データ
```

現時点では`AGENTS.md`、`README.md`、`assets/images/`を先に用意しています。`inputs/`、`rules/`、`src/`などは、制作開始時に資料と技術構成に合わせて配置します。

## Codexへ渡す必須資料

`inputs/`へ次の資料を配置してください。

1. `SkillShift_AI_Academy_要件定義書.md`
2. `SkillShift_AI_Academy_LP原稿.md`
3. `SkillShift_AI_Academy_全体ワイヤーフレーム_v2.html`
4. FV完成イメージ
5. FV以降の最終デザインイメージ
6. 必要に応じて競合参考サイトのスクリーンショット

`rules/`へ、過去に作成したLP共通デザインルールを配置してください。ルールのファイル名が異なっていても構いませんが、案件固有の指示と矛盾した場合は`AGENTS.md`を優先します。

## 画像素材の準備

実装用画像は`assets/images/`へ保存します。必要な画像名・推奨サイズ・生成状況は、[assets/images/README.md](assets/images/README.md)で管理します。

最初に必須なのは次の2枚です。

- `hero-desktop.webp`
- `hero-mobile.webp`

この2枚は同じ架空人物・同じ撮影場面で生成し、画像内に文字・ボタン・ロゴ・UIを入れません。FV完成イメージはデザイン見本であり、ページへそのまま貼り付けないでください。

FV以外の写真は、仮画像で実装を始めてから差し替えても構いません。ファイル名と比率を先に固定しておくと、再調整が少なくなります。

## 制作の進め方

一度に全セクションを制作せず、同じCodexチャットで次の4段階に分けます。

### 1. 共通基盤・FV・前半

- ヘッダー
- FV
- 業務カテゴリ帯
- 悩み
- AI活用のBefore／After
- Academy紹介
- できるようになること
- 中間CTA

### 2. 中盤

- 3段階カリキュラム
- 1日の学び方
- 選ばれる理由
- 受講者事例
- 講師紹介

### 3. 後半

- 料金
- サポート
- 受講までの流れ
- FAQ
- 無料説明会
- 申込フォーム
- フッター

### 4. 最終確認

- PC・タブレット・スマートフォンの表示調整
- CTA、アンカー、FAQ、フォームの操作確認
- アクセシビリティ
- 表示速度
- アニメーション
- 仮データと未確定情報の確認

各段階の詳しい指示は、別途作成済みの`SkillShift_AI_Academy_Codex制作指示書.md`を使用します。

## プレビュー方法

このLPは、外部フレームワークやnpmパッケージを使わない静的HTML・CSS・JavaScript構成です。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで`http://127.0.0.1:4173/`を開きます。確認後は`Ctrl+C`で停止してください。

## 公開前に必ず差し替える項目

以下は架空または未確定のため、そのまま実案件として公開できません。

- 正式な料金
- 累計受講者数と継続率
- 実績数値の出典・調査条件
- 受講者事例と掲載許可
- 講師名、写真、経歴
- 返金保証の正式条件
- 運営会社情報
- 特定商取引法に基づく表記
- 個人情報保護方針
- フォームの送信先と自動返信
- GA4、Google広告、Meta Pixelの計測ID

フォーム連携が未設定の間は、入力画面とバリデーションだけを実装し、送信成功を装わないでください。

## フォーム送信連携（指示文3時点）

- 現在の無料説明会フォームは送信先未設定です。ブラウザ内の入力チェックのみを行い、入力内容を外部へ送信・保存・ログ出力しません。
- 接続候補は、承認済みの自社API、サーバーレスFunctions、または契約済みフォームサービスです。正式な個人情報保護方針とデータ保管条件を確認してから選定してください。
- 送信先はソースコードへ直書きせず、公開環境の環境変数またはGit管理外の設定ファイルから読み込み、開発・ステージング・本番で切り替えます。
- 接続時は、送信中のボタン無効化、成功時の明確な完了案内、失敗時の再試行案内、タイムアウト、二重送信防止を実装します。実際に受理できた場合だけ成功表示を出してください。
- スパム対策候補は、サーバー側の入力検証、レート制限、ハニーポット、CSRF対策、必要に応じたプライバシー配慮型CAPTCHAです。
- 公開前に、開催日時データ、通知・自動返信、同意記録、保存期間、削除手順、権限管理、暗号化、個人情報保護方針との整合、エラー時の運用を確認してください。
- APIキー、メール認証情報、秘密情報、個人情報をHTML・CSS・JavaScriptやリポジトリ内へ保存しないでください。

## 完成確認の基準

- 要件定義書とLP原稿の必要セクションが欠落していない
- FVと全体デザインイメージの色・写真・情報階層が反映されている
- 情報を詰め込みすぎず、適切な余白がある
- 同じカードUIが連続していない
- 360px幅でも横スクロールが発生しない
- CTA、FAQ、フォームが操作できる
- キーボード操作とフォーカス表示に対応している
- コンソールエラーがない
- 架空LPであることがフッターに明記されている

## 技術構成・対応環境

- HTML5：セマンティックなランドマーク、`details`／`summary`、`dialog`、フォーム
- CSS：CSS変数、Grid／Flexbox、レスポンシブ、`prefers-reduced-motion`
- JavaScript：モバイルメニュー、事例タブ、フォーム検証、仮情報ダイアログ、固定CTA制御
- 外部フォント、外部UIライブラリ、npmパッケージは使用していません。
- 最終QA確認環境：Codex in-app Browser（Chromium系）、1440px／1024px／768px／390px／360px

## 最終QA結果

- 必須セクション、原稿の主要メッセージ、CTA文言と接続先を照合済み
- 5画面幅で横スクロール、文字・ボタン・料金表・フォームのはみ出しがないことを確認済み
- モバイルメニュー、カリキュラム、事例タブ、FAQ、フォーム、仮情報ダイアログ、スマホ固定CTAを操作確認済み
- フォームは未入力・部分入力・不正メール・日時未選択・同意未チェック・有効入力・連続操作を確認済み
- コンソールエラー、画像・CSS・JavaScriptの404、空アンカー、未作成ページへのリンクはありません。
- 長尺スクリーンショットで見えた固定要素の反復は撮影合成時のみで、通常表示では再現しません。
- Lighthouseは追加パッケージを導入せず、ブラウザで同等項目を確認しています。正式公開環境では実URLで再計測してください。

## 残っている制約

- フォームは送信先未設定のデモで、外部送信・保存・ログ出力を行いません。
- 料金、返金保証条件、受講者事例、講師情報、会社・法務情報、開催日時は公開前の正式確認が必要です。
- 現在のWebP画像は元ファイルを変更していません。公開前に実際の配信サイズと画質を確認し、必要なら別途レスポンシブ画像を用意してください。
- 本サイトはポートフォリオ用の架空サービスです。実サービスとして公開する場合は、正式情報とフォーム基盤を接続してください。
