# 実装用画像素材一覧

このフォルダには、SkillShift AI AcademyのLP内で実際に使用する画像だけを保存します。

FVやLP全体の「完成イメージ画像」はデザイン見本であり、実装用素材ではありません。完成イメージは`inputs/references/`へ置き、ここには入れないでください。

## 制作ルール

- 推奨形式：WebP（必要に応じてAVIFも用意）
- 画像内に見出し、本文、CTA、ロゴ、アイコン、グラフ、UIを入れない
- 実在人物ではなく、商用利用可能な素材または架空人物を使用する
- 受講者事例と講師写真は、架空・仮素材であることを公開前まで明示する
- 同じ人物として扱う画像は、年齢、髪型、服装、顔立ち、色調を統一する
- ネイビー、ニュートラル、自然光を基調にし、紫・ピンクの強いAI表現を避ける
- 元画像をそのまま巨大サイズで配信せず、用途に合わせて最適化する
- ファイル名は下表から変更しない。差し替え時も同名で上書きする

## 画像にしないもの

次の要素は、文字の読みやすさ、レスポンシブ対応、修正しやすさを保つため、HTML/CSS/SVGで制作します。

- FVのコピー、CTA、バッジ、浮遊UI
- Before／After業務フロー
- 成果物カードと業務画面モック
- 3段階カリキュラム
- 1日の学習フロー
- 選ばれる理由
- 料金表
- サポート図
- 受講までの流れ
- FAQ
- 申込フォーム

## ChatGPT画像生成用プロンプト：FV PC版

```text
SkillShift AI Academyのランディングページで使用する、文字なしの実装用ヒーロー写真を生成してください。

架空の30代前半の日本人女性会社員が、自然光の入る現代的で落ち着いたオフィスでノートPCを操作している。人物は画面右側に配置し、左側にはWebサイトの見出しとCTAを置ける、情報量の少ない暗めの余白を十分に確保する。表情は落ち着いた自信と親しみやすさがあり、過度な笑顔やポーズ感は避ける。服装はネイビーまたはニュートラルカラーの上品なビジネスカジュアル。背景にはごく控えめなブルー系の光やガラスの反射を入れ、先進性を表現する。

信頼感のある企業向け広告写真、自然な写真表現、ネイビーとシアンを基調にしたクールで明るいカラーグレーディング。紫・ピンクの派手なAI表現、サイバーパンク、ロボット、過剰なホログラムは使用しない。

画像内に文字、ロゴ、ボタン、アイコン、グラフ、アプリ画面、透かしを一切入れない。16:9、1920×1080px以上。
```

直前に生成したSkillShift AI AcademyのPC版ヒーロー写真と、同じ架空の30代前半の日本人女性会社員、同じ服装、同じオフィス、同じ光と色調で、スマートフォン用の縦構図を生成してください。

画像内に文字、ロゴ、ボタン、アイコン、グラフ、アプリ画面、透かしを一切入れない。4:5、1080×1350px以上。

## 生成後の確認項目

- [ ] 画像内に文字や不自然なUIがない
- [ ] PC版の左側にコピー用の余白がある
- [ ] PC版とスマホ版が同一人物・同一場面に見える
- [ ] 手やPCに大きな破綻がない
- [ ] スマホで顔や手元が不自然に切れない
- [ ] ブランド色と写真の色調が合っている
- [ ] WebPへ変換し、表のファイル名で保存した
