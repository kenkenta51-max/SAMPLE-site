## 1. 概要

| 項目 | 内容 |
| --- | --- |
| サイト名 | STRIDE LAB（ストライド ラボ）※仮。変更可 |
| slug | `stride-lab`（公開URL: `https://kenkenta51-max.github.io/SAMPLE-site/sites/stride-lab/`） |
| 業種 | 架空のスニーカーショップ（オリジナルブランドのみ扱う研究所型ストア） |
| サイト種別 | 複数ページのブランド＆ECサイト＋ゲーム・体験コンテンツ |
| 雰囲気 | クール・先進的（暗い背景、ネオン、グリッド、スクロール演出） |
| ターゲット | 18〜30歳。スニーカー・ストリートカルチャー・ゲームが好きな層 |
| 目的（サンプルとして見せたいこと） | ①世界観の作り込み ②動くカスタマイザー ③ミニゲームと購買体験の連動 ④複数ページ間で状態（カート・解放コード）を保つ実装 |
| 注記 | 架空の店舗・商品。注文・決済・抽選はすべてデモ。実在ブランドのロゴ・名称・形状は使わない |

### コンセプト
「歩く、を実験する。」
STRIDE LABは、走り方・歩き方のデータからスニーカーを設計する架空のラボ兼ストア。サイトに来た人は「被験者（TESTER）」として扱われ、ラボで自分の1足を組み立て、ゲームで限定モデルの購入権を獲得する。

### キャッチコピー案
- メイン：`WALK IS AN EXPERIMENT.` ／ 歩く、を実験する。
- サブ：あなたの一歩から、次の一足をつくる。
- ドロップ：`SYNC TO UNLOCK.` ／ リズムを合わせて、限定モデルを解放せよ。

## 2. デザイン

### カラー
| 役割 | 色 | 用途 |
| --- | --- | --- |
| 背景 | `#07080C`（ほぼ黒の青） | 全ページの基本背景 |
| 面 | `#11141C` / 罫線 `#232838` | カード・パネル・グリッド線 |
| 文字 | `#E8ECF4` / 補助 `#8A93A8` | 本文・注記 |
| アクセント1 | `#C6FF3D`（ボルトグリーン） | CTA、選択中、スコア |
| アクセント2 | `#7A5CFF`（エレクトリックバイオレット） | グラデーション、ホバー光 |
| 警告/限定 | `#FF4D6D` | LIMITED・残り時間 |

ライトモードは作らない（世界観を優先）。ただし文字のコントラストはWCAG AA以上を守る。

### 文字
- 欧文見出し：**Unbounded**（Google Fonts）— 太く広い近未来感
- 数字・ラベル：**JetBrains Mono** — 計器・データ表示風
- 和文：**Zen Kaku Gothic New**（500/700）

### ビジュアルの約束
- 背景に薄い方眼グリッド＋ノイズ。セクション見出しに `[01] COLLECTION` のような番号ラベル
- 商品写真は「暗い空間に浮かぶスニーカー＋リムライト」で統一（画像プロンプトで揃える）
- 角は小さめ（4〜8px）。線は1px、光は `box-shadow` のネオングロー
- カーソル追従の小さな十字照準（PCのみ、`prefers-reduced-motion` で無効）

### モーション
- FV：スクロールでスニーカーが回転・分解して部品名ラベルが出る（画像レイヤー＋CSS transform）
- 見出し：文字がスキャンラインで現れるテキストリビール
- ページ遷移：画面を横切る光のワイプ（View Transitions API、非対応環境は通常遷移）
- `prefers-reduced-motion: reduce` ではすべての演出を静止表示に切り替える

## 4. ページ別要件

### 4-1. TOP（index.html）
1. **FV**：キービジュアル＋コピー。スクロールでスニーカーが分解（ソール／ミッドソール／アッパー／シューレースの4レイヤー）し、部品ラベルが出る
2. **NEXT DROP**：限定モデルとカウントダウン（常に「次の土曜20:00」までを計算）→ drop/へ
3. **[01] COLLECTION**：6モデルの横スクロールカルーセル → collection/へ
4. **[02] THE LAB**：カスタマイザーの紹介とミニプレビュー → lab/へ
5. **[03] HOW WE BUILD**：設計の3ステップ（計測 → 解析 → 成形）を数字カウントアップで
6. **[04] TESTER VOICE**：架空のレビュー3件（名前はイニシャル）
7. **[05] STORE**：店舗写真と住所（仮）→ store/へ

### 4-2. COLLECTION
- 6モデルのグリッド。絞り込み：カテゴリ（RUN / STREET / TRAIL）、カラー、価格順
- ホバーで別角度の画像に切り替え（画像がない場合は傾き＋光の演出）
- カードからクイックビュー（モーダル）→ サイズ選択してカート追加も可能

### 4-3. PRODUCT（?id=）
- 画像ギャラリー、モデル名、価格、スペック表（重量・ドロップ・クッション値をメーター表示）
- カラー選択（3色）・サイズ選択（22.5〜29.0cm）・数量 → カートへ
- 「LABでカスタムする」ボタン（そのモデルを初期値にしてlab/を開く）
- 関連モデル3件

### 4-4. LAB（カスタマイザー）
- スニーカーは**コードで描いたSVG**（パーツごとに `fill` を変えるため。生成画像は背景・演出に使う）
- 変更できるパーツ：アッパー／ミッドソール／アウトソール／シューレース／ヒールタブ（各8色）、素材（メッシュ・スエード・リフレクティブ）
- 操作：パーツクリックで選択、スマホは下部タブ。ランダム生成、Undo、リセット
- 価格がオプションで変化（リフレクティブ +2,000円など）
- 「デザインコード」（例 `SL-7F3A-21`）を発行し、URLに保存して共有できる
- 完成したらカートへ（カスタム品として表示）

### 4-5. DROP（ミニゲーム「SYNC RUN」）
- 限定モデル紹介、カウントダウン、ルール説明
- **ゲーム内容**：画面上を流れるリング（足音のビート）にタイミングを合わせてタップ/スペースキー。30秒・PERFECT/GOOD/MISS判定、コンボ、スコア
- 音：Web Audio APIで合成したオリジナルのビート（外部音源なし）。ミュートボタン付き、初回は無音
- スコア8,000点以上で「購入権コード」を獲得 → 限定モデルをカートに入れられる（コードは localStorage に保存）
- ベストスコア保存、結果画面にシェア用テキストのコピーボタン
- キーボード操作可。`prefers-reduced-motion` 時は演出を簡略化

### 4-6. STORE
- 店舗写真（外観・内観）、住所・営業時間（すべて仮）、地図はイラスト風のSVG
- 「フットスキャン予約」のデモフォーム（日時選択 → 確認 → 完了。送信はしない）
- FAQ（アコーディオン、6問程度：サイズ交換、配送、限定ドロップ、カスタムの納期など）

### 4-7. CART
- 商品一覧（通常品・カスタム品・限定品）、数量変更、削除、小計・送料（10,000円以上無料）
- 注文情報入力 → 確認 → 完了（注文番号を表示）。**決済・送信は行わない**ことを明記

## 6. 技術仕様

- 素のHTML・CSS・JavaScript（ビルド不要）。外部ライブラリは原則なし（必要ならGSAPのみ、CDNはバージョン固定）
- **リンクはすべて相対パス**（`/`始まり禁止）。SAMPLE-siteは `/SAMPLE-site/sites/stride-lab/` 配下で公開されるため
- 共通ファイル：`assets/css/base.css`・`assets/js/common.js`（ヘッダー、カート、トースト）・`assets/js/data.js`
- 状態は localStorage（`stride-lab:cart`、`stride-lab:unlock`、`stride-lab:best`）。使えない環境でもエラーにしない（try/catch）
- 画像は `assets/img/` に WebP（品質80前後）。FV以外は `loading="lazy"`、`width`/`height` を必ず指定
- レスポンシブ：360px〜1440px。スマホではナビをハンバーガー、カスタマイザーは下部タブ
- アクセシビリティ：見出し階層、`alt`、フォーカス表示、ボタンは `<button>`、ゲームは開始/一時停止をキーボードで
- 各ページに `title`・`description`・OGP（`og:image` は `assets/img/ogp.jpg`）

### フォルダ構成
```
sites/stride-lab/
├── index.html / collection/ / product/ / lab/ / drop/ / store/ / cart/
├── assets/css/  base.css, pages/*.css
├── assets/js/   common.js, data.js, lab.js, game.js, cart.js
├── assets/img/  （画像素材。下表）
├── docs/        brief.md, image-prompts.md（公開対象外）
└── README.md
```
